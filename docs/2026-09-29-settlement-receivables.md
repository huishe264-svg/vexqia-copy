# 日別精算と未収の分割返済（2026-09-29）

## 動作

- 備品・消耗品の入力欄を初期状態で閉じる。開閉で入力途中の金額は消さない。
- レジ金と備品・消耗品に全体履歴を追加。50件ずつ読み込み、従来の10件／8件表示より前まで閲覧できる。
- 日別精算一覧に曜日を表示。精算前も回収済み会計の合計から出前等を引いた総売上を表示する。未収は総売上に含めない。
- 前回の未収伝票を選択後、「今回返済する金額」を入力できる。
- 例：元金110,000円、当日の飲食代5,000円なら、カード会計15,000円のうち10,000円を返済分に指定。残り100,000円は元の未収伝票から現金で別途回収登録できる。
- 元伝票の金額は保持し、返済の割当額と未収残額を別に保存する。部分返済後も元伝票から追加回収できる。
- 入金伝票を減額すると、その伝票に当初指定した当日飲食代を優先して残し、返済割当額を減らして未収残額へ戻す。返済のみの伝票なら減額分すべてが未収へ戻る。削除時はその伝票の割当分だけ戻し、他の返済は保持する。
- 過払い、他店舗・担当外の回収、回収済み元伝票の直接編集を拒否する。精算済み入金伝票は既存の精算取消手順が必要。
- 一括会計と単独回収の再試行は登録IDで二重登録を防ぐ。
